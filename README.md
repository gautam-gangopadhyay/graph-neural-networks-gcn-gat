# graph-neural-networks-gcn-gat
Research-oriented machine learning project implementing Graph Convolutional Networks (GCN) and Graph Attention Networks (GAT) for predictive modeling on structured graph data. Explores graph representation learning, graph theory, attention mechanisms, mathematical modeling, and deep learning using Python, PyTorch, and PyTorch Geometric
# Graph Neural Networks: GCN & GAT

## Overview

Research-oriented implementation and comparison of Graph
Convolutional Networks (GCN) and Graph Attention Networks (GAT)
for graph-based predictive modeling.

## Objectives

- Understand graph-based representations
- Implement GCN
- Implement GAT
- Compare predictive performance
- Study the effect of graph structure
- Analyze attention mechanisms
